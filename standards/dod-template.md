# Definition of Done

A Definition of Done defines the quality every task must meet before merging into `main`, complementing feature-specific acceptance criteria.

- Acceptance criteria met
- Implementation matches the specification and module boundaries
- Formatting, linter, and type checks pass with zero errors
- Smoke tests pass
- Build succeeds and git hooks pass
- Specification and ADRs updated if contracts or architecture changed
- Changes self-reviewed and merged via Pull Request
- Service return from /version git SHA
